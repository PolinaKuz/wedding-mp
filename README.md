# Mas Rognon 3D garden plan

Interactive 3D planning model for Polina & Michiel's wedding at Mas Rognon, Carsan, on 31 July 2027.

Open the live page: https://polinakuz.github.io/wedding-mp/

It runs in any modern browser (best on a laptop). Layouts you change with "Move things" are saved only in your own browser.

The site asks search engines not to index it.
